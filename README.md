# ¡Hola! Soy Sandy 👋🌱

Mi formación en Nutrición me enseñó que las mejores decisiones sobre la salud se toman con buena información. Hoy aplico esa misma idea desde otro lugar: los datos.

Me encanta encontrar las historias que hay detrás de los números, sobre todo cuando algo no cuadra. Algunos de mis hallazgos favoritos han salido justo de ahí: de detenerme, cuestionar un resultado y descubrir que había un error escondido.

Estoy dando mis primeros pasos como Data Analyst y me emociona especialmente el sector de alimentos y salud, donde puedo unir mis dos mundos.

Python (pandas, NumPy, SciPy, Matplotlib, Seaborn) · SQL · Power BI · Tableau · Jupyter · Google Sheets
